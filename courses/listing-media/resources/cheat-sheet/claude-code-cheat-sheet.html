Claude Code
Cheat Sheet

The eight things that make it work like a teammate, with the tip most people miss.

CLAUDE.mdYour rulebook

A file Claude reads at the start of every session: your brand, your market, your MLS and disclosure rules. Type /init to start one.

TipKeep it short and specific. A long, vague rule file gets skimmed.

SkillsJobs you repeat

Saved instructions for work you do every week, like a listing description or a seller update. Type / to see yours.

TipTurn any checklist you repeat into a skill, and the result comes out the same every time.

/mcpConnect your tools

Connectors let Claude reach your email, calendar, CRM or documents directly.

TipStop copy-pasting. Connect the tool once and let Claude read what it needs.

/agentsHelpers on the side

Subagents take a side job, like research or a second draft, in their own space, so your main chat stays clean.

TipHand off the research and keep working on the main job.

Shift + TabPlan mode

Claude lays out the plan first and changes nothing until you say so.

TipRead the plan, fix what's wrong, then say "go ahead."

/compactFree up room

Summarizes a long conversation so Claude has space to keep working.

TipStarting a different job? Use /clear for a fresh start. Long, mixed sessions are where mistakes creep in.

EscStop and back up

Press Esc to stop Claude mid-step. Press it twice to go back to an earlier message and try again.

TipHeading the wrong way? Stop early. It's cheaper than undoing later.

/resumePick up where you left off

Reopens an earlier session, history and all.

TipOne session per job (one listing, one client) keeps each one focused.
