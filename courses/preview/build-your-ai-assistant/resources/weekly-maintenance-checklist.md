# Weekly Maintenance Checklist

Ten minutes, once a week. An assistant that nobody maintains quietly drifts: old fees,
a brokerage line that changed, a voice that slid back to generic.

**Week of:** ____________ **Checked by:** ____________

## Before you run the assistant

- [ ] Each active listing has this week's showing export (dated this week).
- [ ] Listing facts were re-checked after any price change or new disclosure.
- [ ] Any source marked STALE in the register has a request out for a current copy.
- [ ] No real client data from last week is sitting in the reference folder by mistake.

## After you run it

- [ ] Read every draft in full before sending. Nothing goes out unread.
- [ ] Every number in each draft matches its source.
- [ ] Every MISSING / STALE / AGENT DECISION item in the checklist got a human answer.
- [ ] Anything you changed by hand, note it below. Repeated hand edits mean the
      instructions need fixing, not you.

## Monthly (first Friday)

- [ ] Re-read the Voice Profile. Does it still sound like you?
- [ ] Re-run the ten-case test log (T01–T10). Record results with today's date.
- [ ] Update the version number on the master instructions if you changed them,
      and write one line in the change history below.
- [ ] Remove reference files for closed or withdrawn listings.
