# Pre-Render Checklist

Renders can cost credits or plan minutes. Check everything that's cheap to check before
you spend anything.

**Video:** ______________________ **Date:** ____________

## Script

- [ ] Script read aloud and timed: ____ seconds (target 15–30).
- [ ] One hook, one point, one CTA.
- [ ] Every fact matches an approved source (listing sheet, official page). Source noted: ________
- [ ] No invented testimonials, firsthand claims, guarantees or protected-class language.
- [ ] AI disclosure line included (spoken, on screen, or both, per your Spokesperson Brief).
- [ ] Brokerage identification included as required.

## Voice

- [ ] Authorized voice selected (own clone or licensed).
- [ ] Pronunciation test done for names, places, numbers (Pronunciation Sheet).
- [ ] Short preview listened to before the full render.

## Look

- [ ] Correct avatar look/setting selected (Visual Style Sheet).
- [ ] Only one planned variation from the master look.
- [ ] Aspect ratio set for where it will be posted (9:16 for Reels/Stories/TikTok).

## Settings

- [ ] Resolution and export settings checked against your plan's limits.
- [ ] Cost or credits for this render known: ________ (check the provider's current pricing).
- [ ] Draft/preview used where the provider offers one.

## Stop if

- Anything above is unchecked.
- You've already re-rendered this video twice for the same problem. Diagnose first
  (Module 5 troubleshooting) instead of paying for a third attempt.
