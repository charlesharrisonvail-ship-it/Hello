Before you buy

Three things we'd rather tell you now

Other courses teach agents to hand a contract to AI and send the client whatever comes back. This one doesn't, and here's why.

01

It won't summarize your contracts for you

A model summarizing a contract can drop a contingency or misread a deadline, and the mistake is yours, not the software's. Explaining what contract terms mean for a client's rights edges toward practicing law. So Module Fourteen teaches the version that holds up: you read it, the model organizes what you read, and an attorney interprets it.

02

It's education, not legal advice

Modules Thirteen and Fourteen cover texting, email and contract habits that apply in every state. Your state can add rules on top, and they change. So every module that touches the law tells you the same thing: consult a local attorney before you rely on it.

03

It assumes Claude Code is already set up

Module Ten runs a tool called AI Real Estate, which gets installed in Part One. If you don't own Part One, you'll need a paid Claude account, Claude Code installed (it runs in your terminal, and it's not the same as the Claude chat app), and that one tool before Module Ten. Every other module works in whichever chat you already pay for, Claude or ChatGPT. Need Claude Code? Our free install lesson takes about 15 minutes.
