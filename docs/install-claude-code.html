Install Claude Code in about 20 minutes.

Everything in our real estate courses is built in Claude Code. This free lesson gets it running on your Mac or Windows computer, one step at a time. No tech background needed: you’ll copy, paste, and press Enter.

Check your computer

  • Mac: macOS 13 (Ventura) or newer. Check under  menu → About This Mac.
  • Windows: Windows 10 (version 1809 or newer) or Windows 11.
  • At least 4 GB of memory and an internet connection. Almost any computer from the last several years qualifies.
Chromebooks, iPads and phones can’t run this install. Use a Mac or Windows computer.
3

Open the terminal: your typing window

Every computer already has a plain typing window called the terminal. Here’s all it does:

Right now you only open it. Nothing to type yet.

Tap your computer:

On your phone? Pick the computer you’ll use.

Black window with no PS? That’s Command Prompt. Close it and search PowerShell again.
Leave this window open. Step 4 pastes into it.
4

Paste the install command

Click Copy, click inside the terminal window, paste, and press Enter. It takes a minute or two. Let it finish.

Paste with ⌘ Command + V:

curl -fsSL https://claude.ai/install.sh | bash

Paste with Ctrl + V (or right-click):

irm https://claude.ai/install.ps1 | iex
Windows: Git for Windows helps Claude Code work its best, and our courses need it. Step 7 installs it for you.
These commands come straight from Anthropic’s official install guide. Only paste commands from sources you trust.
5

Check it worked, then sign in

  1. Close the terminal window and open a new one (same as step 3). This lets your computer find the new program.
  2. Paste this and press Enter:
    claude --version
    You should see a version number followed by (Claude Code). That means it’s installed.
  3. Make a folder for your work and step into it. Everything Claude Code makes will be saved here.
    mkdir -p ~/AiRE && cd ~/AiRE
    mkdir $HOME\AiRE -Force; cd $HOME\AiRE
  4. Now start Claude Code:
    claude
  5. Pick a color theme and press Enter.
  6. When it asks how to log in, choose Claude account with subscription. The other choice bills you per use instead of through your $20 plan.
  7. Your web browser opens. Sign in with the same Claude account that has your paid plan, click Authorize, then go back to the terminal.
  8. If it asks whether you trust the files in this folder, choose Yes. It’s your AiRE folder.
  9. If Claude Code ever asks whether to use an API key, answer No. Your subscription covers you.
6

Say hello

You’ll see a box where you can type. Type in plain English, just like texting, and press Enter. Try:

I'm a real estate agent. In plain English, what are five things you can do for my business?

To leave Claude Code, type /exit or press Ctrl + C twice. To come back any time, open the terminal and type claude.

7

Get ready for our courses

The course tools need three more free programs: Node.js, Git and Python. Install them once, in the terminal (not inside Claude Code; type /exit first if you see Claude’s box).

  1. Download the LTS installer from nodejs.org, open it, and accept the defaults.
  2. In the terminal, paste this. If a box asks to install developer tools, click Install and wait for it to finish (it can take a while):
    git --version
  3. That same developer-tools install also gives you Python. Nothing extra to do; you’ll check it below.
  1. Paste each line and press Enter, one at a time:
    winget install -e --id OpenJS.NodeJS.LTS
    winget install -e --id Git.Git
    winget install -e --id Python.Python.3.12
If typing python ever opens the Microsoft Store instead, use py in its place. That’s a Windows shortcut, not a problem with your install.

Close the terminal, open a new one, and check all three. Each should print a version number:

node -v
git --version

Mac:

python3 --version

Windows:

py --version
Stuck? Start Claude Code and ask it in plain English: “Install Node.js LTS, Git and Python 3 on this computer and check that they work.” It will walk through it with you.

Everything that gets installed

So nothing surprises you later, here is every program the two courses use, what it does, and where it comes in. All are free except your Claude plan and Higgsfield credits.

  • Claude Code (step 4): the AI that does the work. Needs your Claude Pro plan.
  • Terminal / PowerShell: already on your computer. It’s the window you type install lines into.
  • Node.js (step 7): runs the course tools. It also gives you npx, which installs the design skills in Part One, Module Three.
  • Git (step 7): lets Claude Code download tools from GitHub.
  • Python (step 7): runs the AI Real Estate tool for comps and market reports (Part One, Module Three; Lead to Keys, Module Three).
  • ffmpeg: stitches the Listing Showcase video together. Installed in Part One, Module Five.
  • Higgsfield: makes the drone flight and animates the rooms. A paid service, connected in Part One, Module Three.
  • Apify (optional): pulls photos from a live listing link. Skip it if you already have your photos.
You don’t need Codex or any other coding tool. Claude Code is the only one the courses use.

If something goes wrong

  • “command not found” or “not recognized” after installing: close every terminal window, open a new one, and try again. Still stuck? Restart the computer.
  • Windows says “'irm' is not recognized”: you opened Command Prompt instead of PowerShell. Go back to step 3 and open PowerShell.
  • Signed in with the wrong account? Inside Claude Code, type /login to switch.
  • It says your plan doesn’t include Claude Code: you signed in with a free account. Upgrade in step 1, or sign in with the account that has the paid plan.
  • Want a full health check? Paste this for a plain-language report:
    claude doctor
  • Anthropic’s troubleshooting guide covers every error message.
Prefer to skip the terminal? Anthropic also makes a Claude desktop app that includes Claude Code. Our courses teach the terminal because it’s where the most powerful tools run.
