From the live class

One photo. One red line. One drone flight.

This is the exact example taught in the live class. No drone, no pilot, no weather window. A photograph, a line you draw in Paint, and a simple prompt.

The prompt used in class

“Help me write an expert cinematic drone prompt for this Paris picture. Follow the red line for the flight path and the white arrows for the camera to pan.”

Upload both pictures, the original and your marked-up copy, with that line. Want a bird’s-eye glide instead of a drone? Say so. In class, ChatGPT wrote the strongest prompt; Google Flow came second, and it’s free.

The Paris photo is itself AI-generated, used for practice. On a real listing, use your own photo, check every frame, and label it as AI.

Questions people ask

Before you spend $67

Claude, Claude Code or ChatGPT — which do I need?
The building happens in Claude Code: installing the tools, running the skills, making the videos. Claude Code is not the Claude chat app. It runs in your computer's terminal, it comes with a paid Claude plan ($20 a month), and Module Two walks you through it step by step. For writing prompts and copy, use whichever chat you already pay for. And the habit the whole course runs on: before you make anything, ask the chat to write the prompt for you and tell you which model to use.
Do I need to be technical?
No. Module Two is the ground floor — accounts, terminal, what a skill is, how to hold an API key. Then Module Three walks the setup slowly with every command on screen.
Will this still work in six months?
The tools change constantly. That's why updates are included — when something shifts, I re-record the module and you get it.
Can I use this on any listing?
Use it on your own listings, where you control the photos or hired the photographer. Listing photos belong to somebody — usually the photographer or the listing brokerage. The course covers this properly.
