# AiRE Estate on Instagram and TikTok: account setup

Charles makes the accounts himself, on his phone: both apps text a code to a
phone number and ask for a birthday, which Claude cannot do for him. About 20
minutes for both. Everything to type is below; copy and paste it.

**Before you start**
- Use **hello@aireestate.com** for both, not a personal email.
- The display name is **AiRE Estate** everywhere. Your own name stays off the
  public profile (`recall.py fronted`); the private account owner can be you.
- Profile picture for both: `marketing/social/page/facebook-profile-720.png`
  (the same one the Facebook page uses).
- Link for both: `https://learn.aireestate.com`
- This belongs to the **AiRE Estate** business portfolio in Meta, never the NBMH
  one, and never anything Epique or EpiVail.

## Instagram

Create it through the Facebook page, so Meta knows the two belong together.
That later lets the same "Aire Poster" access post to Instagram too.

1. Install Instagram, tap **Create new account**, sign up with
   hello@aireestate.com.
2. **Username**: try these in order and take the first one that is free:
   `aireestate`, `aire.estate`, `aireestate.courses`, `learn.aireestate`.
3. **Name**: `AiRE Estate`
4. Profile → **Edit profile** → **Switch to professional account** →
   **Business** → category **Education**. Skip contact options except email.
5. Still in Edit profile → **Page** → connect the **AiRE Estate** Facebook page
   (ID 1345476315318631). If it asks which business portfolio, pick
   **Aire Estate**.
6. Paste the bio and link below, set the profile picture, and you're done.

**Bio** (139 of 150 characters):

    AI courses for working real estate agents.
    Taught by a licensed, practicing agent.
    What it costs, and what it won't do.
    Free first lesson ↓

**Link**: `https://learn.aireestate.com` (Edit profile → Links → Add external link)

## TikTok

1. Install TikTok, sign up with hello@aireestate.com.
2. **Username**: same order as Instagram; matching handles help people find you.
3. **Name**: `AiRE Estate`
4. Profile → ☰ → **Settings and privacy** → **Account** → **Switch to Business
   Account** → category **Education**.
5. Edit profile: paste the bio, set the picture, add the website.

**Bio** (63 of 80 characters):

    AI courses for real estate agents. No hype. Free first lesson ↓

**Website**: `https://learn.aireestate.com`. If TikTok does not show a website
box yet (it can hold it back on new accounts), the bio already says where to go;
add the address to the bio as plain text instead.

## Every time you post

- Turn on the AI label when anything in the post was made with AI: Instagram,
  **Advanced settings → Add AI label**; TikTok, **More options → AI-generated
  content**. The caption says "Made with AI" too.
- Captions come from the `aire-social` skill and reels from `aire-reel-edit`.
  The first month's posts are already written in
  `marketing/aire-estate-social-month-1.md` and the media is in
  `marketing/social/media/`; post the same reel to all three platforms.
- Before posting, look at the picture once more: no "Charles Harrison",
  Claude Code says "(not included)", prices are $67 and $97.
