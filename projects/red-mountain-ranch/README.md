# Red Mountain Ranch: EpiVail concept

A private pitch for marketing Red Mountain Ranch, Parcel 1: 66 homes for sale on
the Eagle River in Eagle, CO (Griffin Development, LLC; architect Tres Birds). It
is built from the same template as `../dowd-junction/redesign`.

- `RESEARCH-AND-SOURCES.md` holds every fact, with its source and date, and the
  list of unconfirmed items.
- `site/` is the concept site (Vite, static).

      cd projects/red-mountain-ranch/site
      npm install
      npm run dev        # edit
      npm run build      # static site in dist/

preview. EpiVail has no appointment on this project.
